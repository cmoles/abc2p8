Slice 5 spike — cart byte patching

Goal: prove we can rewrite _cartdat in shell.js before boot and hear a different SFX. The shell cart's sentinel SFX is a single A4 quarter-note (240500). If patching works, the "patched" boot will play a clearly different pitch instead. 



    

      How to play: after clicking a "Boot…" button above, an
      iframe with the Pico-8 shell appears below. Click the ▶ play
      button inside the iframe to start the runtime — that click is
      also what unlocks the browser's audio context. Once the cart is running,
      the cart's _init() calls music(0) so playback
      starts immediately. Press z inside the iframe to re-trigger,
      x to stop.
