# Pico-8 runtime

These files are produced by Pico-8's `EXPORT shell.html` and committed
verbatim. They are **build inputs**, not generated by CI.

- `shell.html` — page chrome and the boot script (`p8_run_cart`).
- `shell.js` — the Pico-8 runtime + the cart ROM as a `_cartdat` JS array.
  The web playground rewrites this array's body at runtime before the
  script executes; everything else (Lua bytecode, runtime functions) is
  untouched.

## Version pinning

- Pico-8: **0.2.6** (per `shell.html` header comment)
- Cart format: **version 43** (per `shell.p8`)

If Pico-8 is upgraded and the runtime is re-exported, verify the
`_cartdat` array shape in `shell.js` (line 3) is still `var _cartdat=[ ... ];`
and that the cart-load entry point is still `p8_run_cart()` in
`shell.html`. If either changes, the playground's patcher in
`web/src/cartPatch.ts` and `web/src/player.ts` will need updates.

This export is pure JS — no `.wasm` file is produced. Don't go looking
for one.
